Why focal

Small tool. Sharp results.

Everything you need to go from a memory card to a finished clip — and nothing you don't.

EXIF-ordered

Sorts frames by DateTimeOriginal so your timelapse always flows in true capture order — falling back to file modification time when EXIF is missing.

Zero-config FFmpeg

No FFmpeg? focal downloads a native static build (real arm64 on Apple Silicon) into its cache on first use. Already have it? It just uses yours.

Live progress bar

Parses FFmpeg's progress stream into a clean [██████░░░░] 60% bar on your terminal — and degrades gracefully to plain lines when piped.

Aspect-ratio guard

Warns when your sequence mixes orientations, and pads output to even, yuv420p-safe dimensions so any source resolution encodes without surprises.

One command

No editing timeline, no scripts to memorize. Point focal at a folder, choose an fps, and get a share-ready MP4. That's the whole workflow.

Single binary

Written in Go, shipped as one dependency-free executable via Homebrew. Fast to install, fast to run, nothing left behind.

Install

Up and running in seconds

The recommended path is Homebrew. Prefer Go or a raw binary? Those work too.

HomebrewRECOMMENDED
$ brew tap victoraldir/tap
$ brew install --cask focal
Go install
$ go install github.com/victoraldir/focal@latest
Verify
$ focal version
focal 0.1.0
  commit:   7c1d48f
  platform: darwin/arm64

Good to know

  • Requires macOS (Apple Silicon or Intel) — native builds for both.
  • FFmpeg is optional. focal fetches a static build into ~/Library/Caches/focal/bin on first use if it's not already on your PATH.
  • The Homebrew cask is auto-published on every release, so brew upgrade --cask focal always gets the latest.
  • Pre-built archives for each release live on the releases page.
Usage

The whole API is one subcommand

Point focal at a directory of photos, pick your output and frame rate, and go.

$ focal lapse --input <dir> --output timelapse.mp4 --fps 30
FlagShortDefaultDescription
--input-irequiredDirectory containing the source photos
--output-otimelapse.mp4Output video file path
--fps-f30Output frames per second
Build a smooth 24 fps timelapse from a shoot
focal lapse -i ~/Pictures/sunset -o sunset.mp4 -f 24
Quick preview at the default 30 fps and output name
focal lapse -i ./frames
Check your installed build
focal version
How it works

Four steps, fully automatic

focal is built on a clean, testable pipeline — each stage does one job and hands off to the next.

01

Scan

Reads image headers for dimensions and resolves each frame's capture time, then sorts the sequence oldest-first.

→
02

Resolve

Finds FFmpeg on your PATH, or downloads and caches a native static build for your Mac.

→
03

Concat

Generates an FFmpeg concat-demuxer file describing every frame and its duration — cleaned up automatically on exit.

→
04

Encode

Renders with an even-dimension pad filter and yuv420p, streaming a live progress bar as it goes.
